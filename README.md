# FitBuddy — Full Stack Fitness & Wellness Platform

## Included modules
- Authentication: Register/Login/JWT-ready backend
- Personalized onboarding/profile
- Dashboard
- BMI calculator
- Workout library
- Workout tracker
- Exercise details, sets/reps/rest
- Nutrition & meal tracker
- Calories + macros
- Water tracker
- Daily goals
- Progress & weight history
- Charts
- Workout history
- Streak & achievements
- Fitness assistant
- Dark/light mode
- Responsive mobile UI
- REST API
- MongoDB/Mongoose models
- Protected API middleware
- Central error handling
- Environment configuration
- GitHub-ready structure

## Run frontend
cd frontend
npm install
npm run dev

## Run backend
cd backend
npm install
npm run dev

Copy `.env.example` to `.env` and add MongoDB URI/JWT secret.

## Note
The frontend has demo/localStorage fallback data so the UI can be explored immediately. Backend APIs are structured for MongoDB integration.
